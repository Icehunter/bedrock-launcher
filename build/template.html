Bedrock Launcher

A native macOS app for Apple Silicon that imports your own Bedrock APK or IPA and signs in to Microsoft.

Run it on your Mac

  1. Press the button. It copies a script that writes the whole project to ~/BedrockLauncher.
  2. Paste it into Terminal and press Return.
  3. Run cd ~/BedrockLauncher && swift run (needs Xcode or the Command Line Tools; first build takes about 1 to 2 minutes).
